# TermSE

**Harnessing Terminal Signal-Aware Deep Learning for Accurate Multi-Class Secreted Effector Identification**

---

## 📌 Overview

TermSE is a deep learning framework for multi-class prediction of secreted effector proteins across multiple secretion systems (T1SE–T6SE).
The model explicitly captures terminal signal patterns by integrating global sequence representations with N- and C-terminal feature learning.

---
